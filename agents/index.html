Agents

My coding agents run on my own machine. From any device I can see each one, send it a prompt, and approve whatever it is waiting on.

Open my agents

How it works

  1. Every agent session on my computer connects to Claude Code Remote Control under its own name.
  2. The link above opens the list of sessions (on a phone, the Claude app under Code works too). It needs my sign-in.
  3. Pick an agent to read what it is doing, type the next instruction, or answer a permission prompt or question. The agent on my computer picks it up straight away.
